# 📝 Todo CRUD API – FastAPI & SQLAlchemy

A simple **Todo List CRUD REST API** built using **FastAPI**, **SQLAlchemy ORM**, and **SQLite** database.  
This project demonstrates clean backend architecture, database connectivity, and RESTful API design.

---

## 🚀 Features

- Create Todo
- Read All Todos
- Read Single Todo
- Update Todo
- Delete Todo
- SQLite Database
- Auto Table Creation
- Interactive Swagger UI

---

## 🛠 Tech Stack

- **Backend Framework:** FastAPI  
- **ORM:** SQLAlchemy  
- **Database:** SQLite  
- **Validation:** Pydantic  
- **API Docs:** Swagger UI
