# 📝 Modern Todo App 

A **modern and interactive Todo application** that helps users manage their daily tasks efficiently.  
It features a clean and responsive **frontend interface** built with **HTML, CSS, and JavaScript**, and a robust **backend API** powered by **FastAPI and SQLite** for data persistence.

This app is designed to make task management simple, intuitive, and visually appealing, while providing all the essential features you expect from a Todo app.

---

## 🚀 Features

### Task Management
- Add, edit, and delete tasks effortlessly
- Track task completion with checkboxes
- Search for tasks by title or description
- Filter tasks by status: All, Pending, Completed
- Dynamic progress bar showing completed tasks

### User Experience
- Modern dark theme with gradient highlights
- Responsive layout for all screen sizes
- Modal popup for editing tasks
- Smooth animations and interactive buttons

### Backend & Data
- FastAPI backend providing a RESTful API
- SQLite database storing tasks persistently
- Automatic task ID generation
- Tracks completed and pending tasks

---

## 🛠 Tech Stack

- **Backend:** FastAPI, SQLAlchemy ORM, SQLite  
- **Frontend:** HTML, CSS (Poppins font), JavaScript  
- **API & Validation:** Pydantic  
- **UI Features:** Dark mode, modals, progress bar  

---

## 💡 Usage Overview

- Add tasks by entering a title and optional description.
- Edit or delete existing tasks using the intuitive buttons.
- Mark tasks as completed using the checkbox; progress bar updates automatically.
- Use search and filter tools to quickly find or organize your tasks.
- All task data is saved in the local database and persists between sessions.
